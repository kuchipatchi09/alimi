# 시험 플래너

과목별로 공부·수행평가 할 일을 관리하는 개인용 시험 플래너입니다. 서버나 로그인이 필요 없는 순수 정적 웹앱이라 GitHub Pages에 그대로 올리면 됩니다.

## 기능

- 과목을 직접 추가하고 색상·시험일(D-day)을 지정
- 과목별로 공부/수행평가/기타 할 일 추가, 마감일 설정
- 체크박스로 완료 표시, 드래그로 순서 변경
- 전체/진행중/완료 필터
- 과목별 진행률 바 + 전체 진행률 원형 그래프
- 대시보드에 마감 임박 항목 모아보기 (D-day 순 정렬, 지남/오늘/D-n 표시)
- 다크/라이트 테마 전환
- 데이터는 이 브라우저(기기)에만 저장 — JSON 내보내기/불러오기로 백업 및 기기 이동 가능

## 왜 GitHub Pages가 잘 맞는가

이 앱은 브라우저 안에서만 동작하는 정적 사이트(HTML/CSS/JS)이고, 데이터도 서버 없이 브라우저 저장소에만 저장됩니다. 이런 구조에는 별도 서버·데이터베이스가 필요한 방식보다 **GitHub Pages, Netlify, Vercel** 같은 정적 호스팅이 가장 간단하고 무료입니다. 개인 사용 목적이라면 GitHub Pages로 충분하고, 이미 계획하신 방향이 정답입니다.

다만 한 가지 참고하실 점: 브라우저 저장소(localStorage)는 **기기·브라우저별로 따로 저장**됩니다. 즉 휴대폰과 PC에서 데이터가 자동으로 동기화되지 않아요. 여러 기기에서 쓰고 싶다면
1. 상단 메뉴(⋯) → "JSON으로 내보내기"로 백업 파일을 받고,
2. 다른 기기에서 같은 사이트를 열어 "JSON 불러오기"로 가져오면 됩니다.

정말로 자동 동기화가 필요해지면, 나중에 Firebase(무료 티어) 같은 간단한 클라우드 저장소를 붙이는 방법도 있습니다 — 지금 구조를 크게 바꾸지 않고 확장할 수 있어요.

## GitHub Pages에 배포하는 방법

1. GitHub에서 새 저장소를 만듭니다 (예: `study-planner`).
2. 이 폴더 안의 `index.html`, `style.css`, `script.js` 세 파일을 저장소 루트에 업로드합니다.
3. 저장소 **Settings → Pages** 메뉴로 이동합니다.
4. "Source"를 `main` 브랜치, 폴더는 `/ (root)`로 설정하고 저장합니다.
5. 1~2분 뒤 `https://<본인계정>.github.io/study-planner/` 주소로 접속하면 바로 사용할 수 있습니다.

## 로컬에서 미리 보기

인터넷 연결 없이 그냥 `index.html` 파일을 더블클릭해서 브라우저로 열어도 대부분 동작합니다. (아이콘 폰트는 CDN을 쓰기 때문에 최초 로드 시 인터넷이 필요합니다.)

## 파일 구조

```
study-planner/
├── index.html   # 구조
├── style.css    # 디자인 (다크/라이트 테마)
└── script.js    # 로직 (저장, 렌더링, 이벤트)
```
